# Practical 14 — Part A, Problem 2

## Requirements
- JDK 17 or newer
- Maven installed and available in PATH

## Run tests
```bash
mvn test
```

## Build runnable JAR
```bash
mvn package
```

## Run application
```bash
java -jar target/counter-project-1.0.jar
```

The app saves its count in `counter-data.txt` in the current working directory. Choose option 3 to save, then exit and restart to check automatic loading.
